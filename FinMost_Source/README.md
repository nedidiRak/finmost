# ФинМост

Работающий браузерный прототип финансового навигатора для трека «Финтех без границ: банк будущего для бизнеса и клиентов», Академия Финтеха 2026.

Основной пользователь — начинающий банковский клиент 18–22 лет. Он рассчитывает личный план, видит последствия изменения сумм, разбирает рискованную ситуацию и закрепляет навык коротким уроком. Дополнительный сценарий — платёжный календарь ИП.

## Запуск за минуту

Откройте `dist/index.html` в современном браузере. Установка и ключи API не нужны. Для предсказуемого хранения и тестирования можно запустить локальный сервер:

```bash
python -m http.server 8000 --directory dist
```

Откройте `http://localhost:8000`. В Windows вместо `python` может использоваться `py`.

В комплекте конкурсных материалов также есть автономный `FinMost.html`, который открывается одним файлом без сервера.

## Что реализовано

- Обзор в личном и предпринимательском режиме.
- Личный бюджет: доходы, обязательные и необязательные расходы, долги, резерв, ежемесячный взнос. Расчёт остатка, цели и срока.
- Платёжный календарь на восемь недель: редактирование сумм, поиск отрицательного остатка, перенос платежа, задержка поступления, сравнение вариантов.
- Три сценария безопасного решения с объяснениями по открытым правилам.
- Десять уроков и 30 вопросов, включая четыре интерактивных задания. Лучшие результаты, повторение без повторных баллов.
- Сохранение на устройстве, журнал до 500 событий, экспорт JSON/CSV, восстановление JSON, сброс, крупный текст.
- Адаптивная разметка, навигация с клавиатуры, диалоги, описания графиков.

## Сценарий демонстрации

1. Откройте «Мой бюджет». Замените взнос 8 000 ₽ на 10 000 ₽. Остаток изменится с 5 000 ₽ на 3 000 ₽, срок — с 12 на 10 месяцев. Сохраните план.
2. Откройте «Безопасные решения». Разберите звонок из «банка» и отложите учебный перевод.
3. В «Платежах бизнеса» у исходного примера дефицит 10 000 ₽. Перенесите 20 000 ₽ со второй на четвёртую неделю: минимум станет +10 000 ₽. Итоговые платежи и остаток конца периода сохранятся. Такой перенос требует договорённости с контрагентом.
4. Пройдите урок. На экране результатов появятся баллы, ответы и события.
5. Скачайте JSON, обновите страницу и убедитесь, что данные сохранились.

## Проверки

Для тестов нужен Node.js 18 или новее. Само приложение Node.js не требует.

```bash

npm run check
```

Проверяются формулы бюджета, пограничные значения, сохранение итогов календаря при переносах, правила риска, повторное начисление баллов и проверка импортируемых данных. Ручная браузерная проверка описана в `docs/TEST_REPORT.md`.

## Границы MVP

Нет банковских API, реальных переводов, авторизации, серверной аналитики и генеративного ИИ. Тренажёр безопасности не определяет, является ли конкретный человек мошенником, и не подменяет банковский антифрод. Недельный прогноз не обнаруживает разрыв внутри недели. Данные синтетические, календарь зафиксирован на 26.10–20.12.2026.

Данные остаются в `localStorage` текущего браузера. Экспорт содержит введённые суммы. На общих устройствах используйте только учебные значения. При запрете локального хранения приложение работает до закрытия страницы и предлагает экспортировать отчёт.

## Развитие

После проверки пользовательской гипотезы: банковская SSO, сервер в контуре заказчика, PostgreSQL, управление доступом, согласия и сроки хранения, обезличенные события, интеграционный адаптер и ежедневный календарь. Промышленная совместимость и соответствие требованиям банка в текущей версии не подтверждены.

## Происхождение и права

Предоставленный участниками `index (2).html` использован как исходная концепция финансового обучения. ФинМост реализован заново: расширены сценарии, расчёты, прогресс и материалы. Для разработки использована помощь ИИ. Сторонние JS/CSS-библиотеки, шрифты из сети, изображения и ключи API в приложении не используются. Права на предоставленные участниками материалы и выбор лицензии для открытого репозитория нужно подтвердить командой.
