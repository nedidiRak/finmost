# Две ссылки на российское облако для конкурсной формы

Официальный формат сдачи требует Яндекс Диск или Облако Mail для презентации и аналитики. Наш публичный сайт содержит резервные копии материалов, но его адрес не подменяет эти два поля.

## Что уже подготовлено

Распакуйте `FinMost_For_Cloud.zip`. Внутри находятся две папки:

- `01_Presentation` — `FinMost_Presentation.pdf` и редактируемый `FinMost_Presentation.pptx`.
- `02_Analytics` — `FinMost_Project_Analysis.pdf`, `FinMost_Financial_Model.xlsx`, описание проекта, план исследования, архитектура и описание уроков. PDF включает аудиторию и альтернативы, допущения экономики, метрики и план внедрения. Формулы доступны в Excel.

Архив нужно распаковать перед загрузкой: две отдельные ссылки на папки удобнее и точнее соответствуют форме, чем одна ссылка на весь ZIP.

## Яндекс Диск

1. В своём браузере откройте https://disk.yandex.ru и войдите в свой аккаунт.
2. Создайте папку `ФинМост — Академия Финтеха 2026`.
3. Загрузите в неё обе распакованные папки. Их можно переименовать в «Презентация» и «Аналитика».
4. У папки «Презентация» выберите **Поделиться** и скопируйте публичную ссылку. Нужен просмотр по ссылке, а не приглашение конкретному пользователю на редактирование.
5. Повторите для папки «Аналитика».
6. Откройте каждую ссылку в отдельном окне без входа в свой аккаунт. Проверьте доступ к PDF презентации, PDF аналитики и скачиванию Excel. Если сервис ограничивает скачивание, устраните это до отправки и повторите проверку.
7. Первую ссылку вставьте в поле презентации, вторую — в поле аналитики.

## Облако Mail

Альтернатива: откройте https://cloud.mail.ru, загрузите те же две папки и создайте для каждой публичную ссылку через действие **Открыть доступ по ссылке** / **Поделиться**. Выберите возможность просмотра и скачивания для всех, у кого есть ссылка, затем проверьте их без авторизации.
