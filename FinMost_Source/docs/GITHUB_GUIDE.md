# Как загрузить ФинМост на GitHub

Приложение уже имеет отдельное онлайн-демо. GitHub здесь нужен для исходного кода и истории изменений. Настраивать GitHub Pages для сдачи не требуется.

Демо: https://finmost-navigator.aquabay4.chatgpt.site

Готовый архив исходников: https://finmost-navigator.aquabay4.chatgpt.site/downloads/FinMost_Source.zip

## Способ 1. Через браузер, без установки Git

1. Скачайте `FinMost_Source.zip`. В Windows нажмите на архив правой кнопкой и выберите «Извлечь всё».
2. Откройте внутреннюю папку `FinMost_Source`. В ней должны находиться `README.md`, `package.json`, папки `dist`, `docs`, `tests`, `scripts` и `.gitignore`.
3. Войдите в свой аккаунт на https://github.com и откройте https://github.com/new.
4. В поле **Repository name** введите `finmost`. Описание: `Финансовый навигатор с интерактивными уроками. Академия Финтеха 2026.`
5. Выберите **Public**, чтобы жюри могло открыть код без приглашения. Не добавляйте автоматически README, .gitignore или лицензию: README и .gitignore уже есть в архиве, а лицензию отдельно не выбирали.
6. Нажмите **Create repository**. На странице пустого репозитория нажмите **uploading an existing file**. Если список файлов уже появился, используйте **Add file → Upload files**.
7. Перетащите в область загрузки **всё содержимое внутренней папки `FinMost_Source`**, включая папки. Не загружайте ZIP как единственный файл и не вкладывайте весь проект ещё в одну папку `FinMost_Source`.
8. В сообщении коммита напишите `Initial working MVP`. Сохраните загрузку в `main`: кнопка может называться **Commit changes** или **Propose changes** в зависимости от экрана. Если открылся диалог подтверждения, завершите его. Дождитесь окончания загрузки.
9. На главной странице репозитория проверьте: README виден сразу, а `dist/index.html`, `dist/app.js`, `dist/engine.js`, `dist/learning.js` существуют. В `tests` должны быть два файла тестов.
10. Скопируйте адрес главной страницы вида `https://github.com/ВАШ_ЛОГИН/finmost`. Это пример структуры адреса: вместо `ВАШ_ЛОГИН` должен быть ваш настоящий логин. Вставьте свою ссылку в поле исходного кода конкурсной формы.
11. Проверьте ссылку в отдельном окне без авторизации. Должны быть доступны README, файлы и история коммитов. У загрузки через браузер будет свой первый коммит — это нормально.

Если GitHub сообщает, что репозиторий `finmost` уже существует в вашем аккаунте, выберите свободное имя, например `finmost-2026`.

## Способ 2. Импорт существующего Git-репозитория

Этот вариант переносит имеющуюся историю Git и не требует скачивания ZIP. Источник — открытый репозиторий, который доступен по обычному Git HTTPS.

1. Войдите в GitHub и откройте https://github.com/new/import. Также можно использовать меню **+ → Import repository**.
2. В поле URL исходного репозитория вставьте:

   `https://finmost-navigator.aquabay4.chatgpt.site/code.git`

3. Выберите владельцем свой аккаунт, имя `finmost` и видимость **Public**.
4. Данные авторизации исходного репозитория оставьте пустыми: источник публичный. Нажмите **Begin import**.
5. Дождитесь завершения. Откройте созданный репозиторий и проверьте файлы и историю.
6. В конкурсную форму вставьте адрес созданного репозитория на GitHub. Если импорт не проходит, используйте способ 1: он не зависит от работы импортера.

GitHub-репозиторий в вашем аккаунте этой инструкцией ещё не создан: эти действия вы выполняете после входа в свой аккаунт.

## Какую ссылку куда вставлять

| Поле конкурса | Что вставить |
| --- | --- |
| Демо | `https://finmost-navigator.aquabay4.chatgpt.site` |
| Исходный код | Адрес вашего публичного репозитория GitHub после загрузки |
| Презентация | Публичную ссылку на папку «Презентация» в Яндекс Диске или Облаке Mail |
| Аналитика | Публичную ссылку на папку «Аналитика» в том же российском облаке |

До создания зеркала на GitHub исходный Git-репозиторий уже доступен по `https://finmost-navigator.aquabay4.chatgpt.site/code.git`, а просмотр файлов и истории — по `https://finmost-navigator.aquabay4.chatgpt.site/source/`. Условия конкурса допускают GitHub, GitLab и иные системы контроля версий. Если используете собственный Git-адрес, укажите рядом страницу просмотра и команду клонирования. Для привычного жюри интерфейса удобнее зеркало на GitHub.

## Проверка исходников на компьютере

Для просмотра приложения достаточно браузера и `dist/index.html`. Готовый автономный `FinMost.html` находится в общем комплекте. Для автоматических проверок нужен Node.js:

```bash
npm test
npm run check
```

Внешних npm-зависимостей у проекта нет.
